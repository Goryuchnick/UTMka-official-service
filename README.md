# UTMka — конструктор UTM-меток

Собирает корректные ссылки для рекламы и объясняет, **что сломается в отчёте**,
если написать метку не так. Не «неверный формат», а «`Yandex` и `yandex` станут
двумя строками, и трафик кампании разъедется надвое».

Работает в браузере и приложением на компьютере. Бесплатно, без рекламы,
код открыт.

## Попробовать

**Веб-версия:** [utmka.alex-pronin.ru](https://utmka.alex-pronin.ru) — открывается и работает
сразу, без регистрации.

**Приложение:** [последний релиз](https://github.com/Goryuchnick/UTMka-official-service/releases/latest)
— Windows (установщик или один файл без установки) и macOS для Apple Silicon и Intel.
Обновляется само.

| Что где хранится | |
|---|---|
| Приложение | файл на вашем диске, `%APPDATA%\UTMka\3.0\` |
| Веб-версия | аккаунт по кодовой фразе: ни почты, ни пароля, в базе только отпечаток фразы |
| Общие данные | по кнопке «Синхронизировать» в приложении — шаблоны и история становятся общими |

⚠️ Приложение не подписано сертификатом: на Windows SmartScreen предупредит о неизвестном
издателе («Подробнее» → «Выполнить в любом случае»), на macOS первый запуск — правой кнопкой
по значку → «Открыть». Инструкция для macOS: [INSTALL_MACOS.md](INSTALL_MACOS.md).

## Что умеет

- **Генератор** в двух режимах: пошаговый с плитками площадок и «всё сразу» — пять полей.
- **Проверки на ходу**: регистр, пробелы, кириллица, `vk` в поле типа трафика вместо площадки,
  закодированные подстановки вроде `%7Bkeyword%7D`, которые площадка не узнает.
- **Справочник значений** — копится сам и ловит расщепления: одно и то же, написанное
  по-разному, сводится одним нажатием.
- **Шаблоны** с тегами и цветами, **история** с поиском и периодом, три вида списка.
- **Пакетный режим** — десятки ссылок разом из таблицы.
- **Разбор чужой ссылки** и **проверка переадресаций**: видно всю цепочку и метки, которые
  по дороге потерялись.
- **QR-код** — вектор для типографии и растр для экрана, **сокращение** через clck.ru.
- **Импорт и экспорт** JSON и CSV, перенос данных из версии 2.2.

## Как устроен репозиторий

```
packages/core/   правила: сборка, разбор, проверки, справочник, слияние — чистый TS без сети и DOM
packages/ui/     экраны, общие для обеих оболочек; внешний мир приходит через алиас #shell
apps/web/        Next.js — utmka.alex-pronin.ru
apps/desktop/    Tauri + Rust: локальный SQLite, сеть, импорт 2.2, обмен с аккаунтом
legacy/          замороженная 2.2 на Python — источник правды по поведению
docs/            архитектура, журнал решений, сборка и выпуск
```

Правила живут в одном месте и едут в обе оболочки — иначе веб и приложение начинают
проверять ссылку по-разному, а это ровно то, ради чего инструмент существует.

## Разработка

```bash
npm ci
npm test              # тесты правил
npm run type-check
npm run dev --workspace @utmka/web     # веб
cd apps/desktop && npx tauri dev        # приложение
```

Подробности — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) (там же журнал решений: что и почему
сделано так, а не иначе) и [docs/DESKTOP-BUILD.md](docs/DESKTOP-BUILD.md) (сборка и выпуск).
