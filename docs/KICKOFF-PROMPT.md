## Правила работы

- Дизайн-система наследуется от «ПРОНИН-ОС»: токены --hv2-*, иконки PixelIcon.
  Своих цветов и шрифтов не заводить. Пиксельный шрифт — Press Start 2P через
  next/font (у Karmatic Arcade кириллица в cmap есть, а глифы пустые — не
  возвращать). ⚠️ Токенов --hv2-magenta и --hv2-amber НЕ существует: амбер —
  --hv2-primary, розовый — --hv2-course, красный — --hv2-destructive.
- Персональных данных не собираем нигде. Кодовая фраза именно для этого.
  Вебвизор в Метрике включать НЕЛЬЗЯ — в полях адреса кампаний и фраза.
- Инструмент обязан работать до входа. Всё, что хранится, — за фразой.
- Никаких платных тарифов и апселлов.
- Перед коммитом: npm test и npm run type-check в корне, затем /review-code.
- Перед деплоем: /secure-audit.
- Отвечай по-русски.

🪤 Грабли этого проекта, на которых уже спотыкались:
- линтер `react-hooks` запрещает setState в теле эффекта и чтение ref в рендере;
  правильный путь — выводить значение из стора либо задавать начальное состояние
  через `key` или ленивый инициализатор (так сброшен отчёт в RedirectCheck);
- `PixelIcon` без размера растягивается на весь флекс-контейнер (дефолт задан,
  но помни при новых иконках);
- элемент с `id="ym"` затирает `window.ym` — таких id в скриптах не давать;
- контент экранов живёт во внутреннем скроллере `.screen-scroll`, а не в окне:
  Playwright с `fullPage` снимет только видимую часть, прокручивать надо сам
  контейнер;
- тур первого визита кроет экран маской и съедает клики — в автотестах ставить
  `localStorage['utmka.onboarding.v2'] = '1'` до загрузки страницы;
- схема, не включённая в Exposed schemas проекта Supabase, даёт `PGRST106` и 500
  на всех ручках хранилища при внешне здоровом контейнере — первое, что
  проверять после переезда или заведения новой базы; диагностируется запросом
  к `/rest/v1/…` с заголовком `Accept-Profile: utmka`.
