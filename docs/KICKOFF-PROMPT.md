## Объём v3.0 — берём всё

Слой правил (работает офлайн, без LLM):
1. Валидация в момент ввода: регистр, пробелы, кириллица, спецсимволы, дубли параметров,
   длина URL, семантические ловушки (medium=organic на платном трафике).
   Каждая ошибка объясняет, ЧТО СЛОМАЕТСЯ В ОТЧЁТЕ, а не просто «неверный формат».
2. Нормализация одним нажатием с показом до/после.
3. Справочник значений: автодополнение, предупреждение о новом значении, детектор
   расщепления («у вас telegram, tg и messenger — это три источника в отчёте»), экспорт.
4. Разбор чужой ссылки: вставил URL → таблица параметров + список проблем + «починить».
5. Пакетный режим: таблица площадок → 20 ссылок за раз, импорт списка, экспорт CSV.
6. Пресеты площадок с динамическими подстановками: Яндекс.Директ ({keyword}, {campaign_id},
   {ad_id}, {source_type}, {device_type}, {region_name}), ВКонтакте, Telegram Ads,
   email-рассылки, офлайн/QR. Пресет объясняет разницу между source и medium.
7. QR-код на готовую ссылку.
8. Проверка редиректов (требует сети): пройти цепочку и показать, дожили ли метки.

Слой LLM (только веб, через routerai, с видимым лимитом на кодовую фразу):
9. Бриф → пакет меток: свободный текст «запускаем осенний набор на Директ, ВК и рассылку»
   → готовый набор ссылок.
   ЖЁСТКОЕ ПРАВИЛО: ответ модели ВСЕГДА прогоняется через слой правил перед выдачей.
   Модель может предложить значение с пробелом или кириллицей — правила последняя инстанция.
   Лимит кончился → инструмент работает дальше, просто без подсказок, без драмы.
