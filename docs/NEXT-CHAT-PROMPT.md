## Как запускать

```bash
cd apps/desktop && npx tauri dev      # окно + Vite на 1420
npm run type-check                     # корень, все воркспейсы
cd apps/desktop/src-tauri && cargo test
```

Rust живёт на `D:\rust` (`CARGO_HOME`, `RUSTUP_HOME`, `CARGO_TARGET_DIR` —
переменные пользователя уже заданы).

🪤 **Порт 1420 после падения `tauri dev` держит осиротевший Node.** Перед
перезапуском:

```powershell
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -match 'vite' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
```

🪤 Скриншот окна средствами PowerShell ловит чужое окно, если оно перекрыло
UTMka: Windows не даёт поднять окно из фонового процесса. Проверять UI лучше
в браузере на `http://localhost:1420` (Playwright), а в самом окне — глазами
владельца. Отличия окна от браузера реальны: WebView2 иначе считает
`color-mix(…, transparent)` (из-за этого CRT-слой заливал экран, см. §11).

## Что нужно починить — по убыванию важности

### 1. Выпадающие панели: прокрутка и ширина

Компоненты `packages/ui/src/components/generator/ValueHints.tsx` (типовые
значения) и `DatePopover.tsx` (календарь), стили — `.vhints-panel`, `.cal`
в `packages/ui/src/styles/globals.css`.

**Баг А — панель схлопывается в узкую полоску**, когда окно не широкое (у полей
«Кампания», «Канал», «Содержание»). На широком окне та же панель открывается
правильно. Появилось после правки, которая подняла контекст наложения:

```css
.input:has(.vhints-panel), .input:has(.cal) { position: relative; z-index: 40; }
```

Из-за неё панель позиционируется от `.input`, а не от `.vhints`. Нужно вернуть
панели нормальный размер, **не потеряв** починку перекрытия: до этой правки
раскрытый список уходил под соседние поля, потому что у `.input` есть
`backdrop-filter`, а он создаёт свой контекст наложения.

**Баг Б — пропала прокрутка внутри панели.** Задумано так: колесо над самой
панелью прокручивает её содержимое, а прокрутка экрана — закрывает панель.
Сейчас закрытие срабатывает на любой `scroll` в фазе перехвата, поэтому
внутренний список прокрутить нельзя. Нужно различать: событие изнутри панели —
не повод закрываться.

### 2. Всё приложение прокручивается целиком

При разворачивании окна на максимум прокручивается вся страница, хотя
прокручиваться должен только `.screen-scroll` внутри корпуса устройства.
Смотри `.dev` (`height: 100dvh`), `.screen`, `.screen-scroll` и новую строку
заголовка `.titlebar` (38px) — вероятно, суммарная высота теперь превышает
экран, потому что заголовок добавился, а `.dev` остался `100dvh`.

### 3. Проверить память настроек

Тема и режим генератора («Просто»/«Эксперт») должны переживать перезапуск.
Код уже есть, но вживую не проверен: `apps/desktop/src/lib/settings-sync.ts`
пишет значения в таблицу `settings`, а Rust возвращает их в `localStorage`
при старте окна (`apps/desktop/src-tauri/src/lib.rs`, блок с `window.eval`).
Проверь: сменить тему и режим → закрыть окно → открыть → должно сохраниться.
Если инъекция не срабатывает до первой отрисовки, перенеси её в
`initialization_script` при создании окна.

### 4. Ревизия функционала 2.2

Владелец просил сверить, что ещё умела версия 2.2 и чего нет в 3.0. Исходники —
`legacy/desktop-2.2/frontend/` (`index.html`, `js/app.js`, `js/ui.js`).
Уже вернули: сортировку списков по колонкам, карточку шаблона, создание
шаблона и значения справочника прямо в библиотеке.
Проверь остальное — по идентификаторам в `index.html` видно: модалка «все

## Правила, которые уже действуют

- Русский язык в коде, комментариях и коммитах.
- Комментарии объясняют **почему**, а не что; грабли помечаются `⚠️` и `🪤`.
- `productName` десктопа — «UTMka 3.0» и менять его нельзя: NSIS ставит в
  `%LOCALAPPDATA%\{productName}` и **вычищает эту папку**, а `UTMka` занята
  версией 2.2 (однажды уже снесли её установку).
- Уникальность имени шаблона держит колонка `name_key`, а не `lower(name)`:
  встроенный `lower()` в SQLite не понижает регистр кириллицы.
- Справочник наполняет `history_add` внутри своей транзакции — отдельной ручки
  быть не должно, иначе счётчики разойдутся с обычной записью.
